# SoftHand — 투자유치 사업계획서 (Seed, 4차 수정본)

**주방 조리 자동화용 로봇 핸드 SoftHand 개발 및 사업화**
사람용 조리도구와 가전을 그대로 사용하는 로봇 핸드와 주방 작업 소프트웨어 · Seed 20억 원 / 24개월 · 1차 목표 시장: 급식·외식 상업용 주방

## 이번 수정 (4차)

3차 피드백("너무 AI스럽고 제품 홍보 같음, 투자를 요청하는 사업계획서가 아님")을 반영해 형식을 전면 전환.

- 구성: 비전·제품 소개 순서 → 사업계획서 순서 (사업 개요 → 문제 인식 → 해결 방안 → 기술 및 개발 현황 → 시장 분석 → 경쟁 분석 → 사업화 전략 → 수익 모델 → 매출·손익 계획 → 추진 일정 → 자금 사용 계획 → 조직 및 인력 → 투자 제안)
- 문체: 영어 표어·컨설팅식 용어와 "A가 아니라 B" 문형 삭제, 사실을 말하는 한국어 제목, 개조식 본문 (본문 한국어 94%)
- 디자인: 개념 도식과 전면 렌더링 대신 표·차트·분기 일정표, 본문 이미지는 제품 콘셉트 1장 (주방 장면은 부록 A5)
- 근거: 통계청 사업체·종사자 수, 부산교육청 학교 급식 조리로봇 실증, 삼성웰스토리 공정별 조리로봇, 시장 전망 범위를 본문에 추가
- 재무: 수치는 그대로, 누적 영업손실과 후속 투자 필요액(1·2년차 16.5억 원 Seed, 3~5년차 17.1억 원 시리즈 A)을 명시

상세 내용은 `SoftHand_IR_Revision_Report` (피드백 분석, 슬라이드별 변경, 문체 점검, 투자 심사 관점 평가) 참고.

## 다시 만들기

재무 모델(`source/deck/model.py`)이 덱과 보고서의 숫자를 함께 관리.

```bash
pip install python-pptx python-docx pillow numpy lxml

python3 source/deck/model.py           # 재무 모델 → source/deck/model.json
python3 source/deck/build.py --pdf     # 덱 + 검토용 PDF
python3 source/deck/make_report.py SoftHand_IR_Revision_Report.md SoftHand_IR_Revision_Report.docx
```

- 글꼴: Noto Sans KR (Regular·Bold). 발표용 PC에 설치되어 있지 않으면 대체 글꼴로 줄바꿈이 달라질 수 있음
- 글자 넘침 검사: `NotoSansKR-400.ttf`·`NotoSansKR-700.ttf`를 `~/.fonts` 또는 `NOTO_KR_DIR`에 두면 실제 글꼴 폭으로 검사
- 검토용 PDF: LibreOffice 사용. 영문·숫자와 한글 사이 자동 간격을 끈 상태로 변환해 PowerPoint 화면과 같은 문장으로 출력
- 보고서의 민감도 문구는 `model.py` 출력값을 옮겨 적은 것이므로 가정을 바꾸면 함께 갱신

**콘셉트 렌더링 (선택)**: three.js r170을 Headless Chromium에서 렌더링.

```bash
cd source/render3d
npm install                          # three@0.170.0, playwright
npx playwright install chromium      # Chromium이 없는 경우만
mkdir -p final
bash batch.sh && python3 make_assets.py                    # 핸드·머신텐딩 장면 → assets/renders/
bash batch_kitchen.sh && python3 make_kitchen_assets.py    # 주방 장면 → assets/renders/kitchen/
```
