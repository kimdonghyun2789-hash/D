## 작성 원칙

- 사실 · 계획 · 가정 · 미확보 근거를 구분해 표기했습니다 (A1 근거 상태).
- 확인되지 않은 고객 · Design Partner · 실적 · 특허 · 성능은 만들지 않았습니다. 성능은 Target, 가격 · 원가 · 매출은 가정입니다.
- 5개년 재무는 Kitchen 매출과 OEM 매출을 제외한 Base Case이며, Kitchen은 Upside로만 다룹니다.
- 외부 수치(IFR World Robotics 2026, IFR Robot Density, BCG)는 출처와 발표 시점을 A17에 적었습니다.
- 모든 SoftHand 이미지는 `CONCEPT RENDERING` 표기를 유지합니다.

## 다시 생성하기

재무모델 · Deck · 보고서는 `source/deck/model.py` 하나를 기준으로 숫자를 공유합니다. 가정을 바꾸면 아래 순서로 다시 만듭니다.

```bash
pip install python-pptx python-docx pillow numpy lxml

python3 source/deck/model.py        # 재무모델 → source/deck/model.json
python3 source/deck/build.py all    # Deck → SoftHand_Founding_Seed_IR_Deck_Final.pptx
python3 source/deck/make_report.py SoftHand_IR_Revision_Report.md SoftHand_IR_Revision_Report.docx
```

- 글꼴: 원본 Deck과 같은 Noto Sans KR 계열(Regular · Medium · SemiBold · Black)을 사용합니다. 설치되지 않은 PC에서는 대체 글꼴로 표시되어 줄바꿈이 달라질 수 있습니다.
- 글자 넘침 검사용으로 `NotoSansKR-400/500/600/700/900.ttf`를 `~/.fonts` 또는 `NOTO_KR_DIR`에 두면 실제 글꼴 폭으로 검사합니다. 없으면 근사치로 검사합니다.
- 보고서의 민감도 문구(`make_report.py`의 `SENS`)는 `model.py` 출력값을 옮겨 적은 것이므로, 가정을 바꾸면 함께 갱신해야 합니다.
- 검토용 PDF는 LibreOffice 렌더링이라 영문과 한글 조사 사이 간격이 PowerPoint보다 넓게 보입니다. 원문에는 공백이 없습니다.

**Concept Rendering (선택)** — three.js r170을 Headless Chromium에서 렌더링합니다.

```bash
cd source/render3d
npm install                          # three@0.170.0, playwright
npx playwright install chromium      # Chromium이 없는 경우만
mkdir -p final && bash batch.sh      # 색상 + 마스크 PNG → final/
python3 make_assets.py               # 배경 합성 → assets/renders/
```
