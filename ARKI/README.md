## 핵심 결과 (Base, 전부 DERIVED from ASSUMPTION)

- 세대 경제성 (구축 Premium · 구매 · 5년): 매출 2,418만원, Lifetime Contribution 458만원 (Y3 원가) → 813만원 (Y5 원가). 설치 시점 매출이 84%이므로 Robot ASP와 BOM이 세대 경제성을 결정함.
- 가격 Gap: 가치 Anchor는 월 11~24만원이지만 원가 기반 Rental은 월 24~31만원 → 고객 지불의사(WTP) 검증이 Seed 1순위.
- Rental Payback: Y3 39개월 → Y5 30개월. Partner 허들 36개월을 넘기려면 BOM이 약 1,060만원 이하여야 함.
- 5개년: 매출 Y5 77.6억원 · 매출총이익률 36% · 영업이익 −36.4억원. 5년 누적 현금 최저점 −128억원, 손익분기는 연 약 1,340세대.
- Sensitivity Top 3: Customer WTP · Robot BOM · Partner Distribution.
- Seed 20억원으로는 24개월 기준 약 5.8억원이 부족함 (수정안 25.8억원, Seed 단독 18.6개월) → TIPS R&D(최대 8억) 연계 또는 25억원 / Bridge.
- Seed VC 판단: **WATCH** — INVEST로 바뀌는 조건 5개는 Founder-Market Fit · Mock-up Proof · WTP 행동 신호 · 평면 30개 Template Coverage · 실재 Partner Pilot 합의.

## 다시 만들기

```bash
pip install python-pptx openpyxl pillow lxml       # LibreOffice: PDF·xlsx 재계산용
python3 ARKI/source/model.py          # 가정·계산 → model.json (sanity assert)
python3 ARKI/source/xlsx_model.py     # 수식 기반 xlsx 생성
python3 <xlsx skill>/scripts/recalc.py ARKI/ARKI_Robotics_Financial_Model.xlsx   # LibreOffice 재계산 (오류 0 확인)
python3 ARKI/source/check_xlsx.py     # xlsx 값 ↔ model.py 교차검증
python3 ARKI/source/build.py --pdf    # 덱 + 검토용 PDF (--png: Slide PNG 미리보기)
python3 ARKI/source/gen_docs.py       # docs/*.md (덱 텍스트·모델 값에서 자동 생성)
```

- 단일 원천: `source/model.py`의 입력(Tag·출처 포함)이 덱·xlsx·문서의 모든 숫자를 생성. 덱의 Slide 문구는 `build.py` 실행 시 추출되어 `docs/01~02`로 들어감.
- 검증 상태 (2026-10-07): xlsx 1,789개 수식 재계산 오류 0 · model.py와 840개 값 일치 · 덱 글자 넘침 검사 0건.
- 글꼴: Noto Sans KR. `~/.fonts/NotoSansKR-400.ttf`·`-700.ttf`가 있으면 실제 글꼴 폭으로 넘침 검사.
- 출처는 2026-10-07 웹 검색 기준(보도 인용 포함). 외부 제출 전 국가데이터처·국토부 보도자료 원문과 대조 필요 (`docs/03`).
